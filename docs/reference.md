# API reference

The topology API is documented from the source, with every exported
function and type and their doc comments:

- **[`@adviser/ovn-fabric`]({{ '/api/index.html' | relative_url }})**:
  `defineNetwork`, `IPv4`/`IPv6`, `runtime()`, and the topology types
  (`Host`, `CollisionDomain`, `Router`, endpoints, services, …)
- **[`@adviser/ovn-fabric/secret-types`]({{ '/api/secret-types/index.html' | relative_url }})**:
  the secrets template of the living example

The same documentation is on [JSR](https://jsr.io/@adviser/ovn-fabric/doc).
For how the pieces fit together, start with the [topology guide](guide/topology.html).

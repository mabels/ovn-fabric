# AGENTS.md — ovn-fabric

## Verification (run before finishing changes)

Use the single verification entrypoint (mirrors `.github/workflows/ci.yaml`):

```sh
./scripts/check.sh                 # full TS + codegen + Python check
./scripts/check.sh --skip-codegen  # when schemas didn't change
./scripts/check.sh --ts-only       # Deno fmt, lint, check, test, smoke
./scripts/check.sh --py-only       # black, ruff, codegen, mypy, unittest
```

If `.venv-build` is missing:

```sh
python3 -m venv .venv-build && .venv-build/bin/pip install black ruff mypy -r requirements.txt
```

## Architecture (data flow & package boundaries)

`src/` (TS DSL) → desired-state IR JSON → `protocol/` → `fabric/` + `raw_reconciler/` → `ladops/`

| Directory | Owns |
| --- | --- |
| `src/` | TypeScript DSL (`defineNetwork`, hosts, routers, routing domains, tenants, workloads) and IR emitter (`src/protocol.ts` is the ArkType schema source of truth). |
| `protocol/` | Python IR dataclasses generated from `src/protocol.ts` (`protocol/generated.py`, `protocol/raw_generated.py`). |
| `fabric/` | Host/cluster deployment planner, emitter, lifecycle, boot/systemd units, and `fabric/schema/` protocol. |
| `raw_reconciler/` | Plan-driven desired-vs-observed graph reconciler, ownership tracking, and natural keys. |
| `primate/` | Learns primitive RawIR templates from a real system (`fabric/rawir_learned.py` is generated by it). |
| `runtime/` | Event-driven host service runtime, IPC transport (`unix`/TCP), peer messaging, journal, and jobs. |
| `ladops/` | Thin typed wrappers around Linux networking, OVS, OVN, OVSDB, netns, iptables, and Docker. |
| `ui/` | Graph UI for visualizing topologies. |
| `docs/adr/` | Architecture Decision Records — check these before changing cross-layer contracts. |

## Generated files (do not hand-edit)

These are generated and excluded from `black`/`ruff` in `pyproject.toml`:

- `protocol/generated.py`, `protocol/raw_generated.py` → `deno run --allow-read --allow-write --allow-run --allow-net --allow-env src/cli.ts generate-pytypes`
- `runtime/generated.py` → `deno run --allow-read --allow-write --allow-run --allow-net --allow-env runtime/schema/generate.ts`
- `fabric/generated.py` → `deno run --allow-read --allow-write --allow-run --allow-net --allow-env fabric/schema/generate.ts`
- `fabric/rawir_learned.py` → generated by `primate/`

## Conventions

- TypeScript: strict compiler options in `deno.json` (`noUncheckedIndexedAccess`, `noImplicitReturns`, etc.).
- Python: `mypy` runs with `strict = true` on `ladops/`, `protocol/`, `raw_reconciler/`, `runtime/`, `fabric/`, and `primate/` (tests included).
